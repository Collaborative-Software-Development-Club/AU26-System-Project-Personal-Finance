# src/components — shared components

Reuse these before writing new ones. Feature-specific components belong in
`pages/<feature>/`.

## `ui/` — shadcn/ui primitives
Generated by `npx shadcn@latest add …` (style `radix-nova`, Tailwind v4, CSS
variables, `radix-ui` package, `cn` for class names). Button, Card, Dialog,
AlertDialog, DropdownMenu, Select, Input, Label, Textarea, Table, Badge,
Progress, Tabs, Sonner, Skeleton, Sheet, Separator, Tooltip, Alert, Checkbox,
Switch, Popover, RadioGroup, ScrollArea, Breadcrumb, Avatar. Add more with the
CLI rather than hand-writing.

Theme tokens live in `src/index.css`. Besides the shadcn set there are finance
tokens: `income`, `expense`, `transfer`, `warning`, `success` (use as
`text-income`, `bg-expense/10`, `border-warning/40`). Chart colours:
`--chart-1..5`.

## `forms/`
`FormField` (label/description/error wiring via `aria-describedby`),
`FormGrid`, `MoneyInput` (raw string + currency), `DateInput`, `MonthInput`,
`SearchInput`, `SelectInput`, `ColorSwatchPicker`, `FormActions` (submit
disabled while pending).

Form pattern:
```tsx
const [values, setValues] = useState<AccountFormValues>(initial)
const [errors, setErrors] = useState<FieldErrors>({})
const save = useAsyncAction(async (input: AccountInput) => store.createAccount(input))
const onSubmit = async (e) => {
  e.preventDefault()
  const errs = validateAccount(values); setErrors(errs); if (hasErrors(errs)) return
  const result = await save.run(toInput(values))
  if (result) { toast.success('Account created'); navigate(`/accounts/${result.id}`) }
}
// render: <FormField label error={errors.name ?? save.fieldErrors.name}>…</FormField>
//         <FormErrorMessage message={save.error} />  (when save.status === 'error')
//         <OutcomeUnknownNotice …/>                   (when save.status === 'unknown')
//         <FormActions pending={save.isPending} … />
```

## `feedback/`
`toast` / `AppToaster` (sonner), `ConfirmDialog`, `EmptyState`,
`NoResultsState`, `ErrorState`, `LoadingSkeleton` (variants page/cards/table/
chart/form/list), `InlineValidationMessage`, `FormErrorMessage`,
`PendingOperationIndicator`, `OutcomeUnknownNotice`,
`UnresolvedOperationsBanner`, `NotificationsMenu`.

Icons: named imports from `lucide-react` only. `vite.config.ts` rewrites them
to per-icon files so the Rolldown optimizer does not hang on the 1800-icon barrel.

## Accessibility checklist for new components
Labelled inputs; errors linked via `aria-describedby`; icon-only buttons have
`aria-label`; decorative icons `aria-hidden`; keyboard operable; visible focus
(`focus-visible:ring-*`); status never colour-only; charts have a text summary.
