# src/api — data access boundary

`FinanceApi` (`types.ts`) is the only contract the rest of the app depends on.
`index.ts` exports a singleton `api`. Today it is `MockFinanceApi`; when the
FastAPI backend exists, add `http/http-api.ts` implementing the same interface
and change one line in `index.ts`.

Nothing outside `src/api` may import from `./mock`. Pages never call `api`
directly — they go through store actions (`src/store`).

## Contract highlights

- Reads: `loadSnapshot()` returns the whole `FinanceSnapshot` (small dataset; a
  real API can page later).
- Writes return the **server's version** of the entity; the store applies that,
  never its own guess.
- Money-moving creates take an **idempotency key** generated by the client
  (`createTransaction`, `createTransfer`, `runImport`). Same key ⇒ same result.
  `lookupTransaction / lookupTransfer / lookupImport(key)` reconcile unknown outcomes.
- Errors are `ApiError { code: validation | conflict | not_found | unavailable | unknown_outcome, details? }`.
  `OutcomeUnknownError` carries the idempotency key.
- Enforced invariants (mirror of what the backend must own): account with
  transactions cannot be deleted; category with transactions needs reassignment;
  transfer legs are written atomically; one budget per category/month;
  transfer source cannot overdraw a non-credit account; currency locked once an
  account has transactions.

## Mock implementation (`mock/`)

| File | Role |
|---|---|
| `mock-api.ts` | In-memory `FinanceSnapshot` + idempotency table; persists after every mutation. |
| `storage.ts` | localStorage read/write with version + shape check; corrupt data ⇒ reseed. Key `pf.mock-db`. |
| `simulation.ts` | Latency (toggle in Settings) and failure markers. |

### Failure markers (for demos and manual testing)
Put these in a description / name / memo / file name:

| Marker | Behaviour |
|---|---|
| `[FAIL]` | `failIfRequested` — rejected with `unavailable`; nothing saved. Most mutations. |
| `[UNKNOWN]` | `loseResponseIfRequested` — **committed**, then `OutcomeUnknownError`. Only `createTransaction`, `createTransfer`, `runImport` (they carry an idempotency key). |
| `[SLOW]` | ~3 s latency on that request. |

Markers themselves are deterministic. When latency is enabled, the delay is a
250–500 ms range (small jitter), not a fixed number.

## Adding an endpoint
1. Add input/response types and the method to `FinanceApi` in `types.ts`.
2. Implement in `mock-api.ts` (validate → mutate → `persist()` → return clone).
3. Add a store action in `store/finance-store.ts` that applies the response.
